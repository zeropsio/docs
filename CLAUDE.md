# Writing docs

- This repository is public. Internal notes, unverified facts and open product questions never go into it.
- Single source of truth: a fact lives on one page. Don't restate it elsewhere, find the canonical section and link it with its anchor. A one-line pointer plus the consequence specific to the page is fine.
- `apps/docs/static/llms.txt`, `llms-full.txt` and `llms-small.txt` are generated from the content by `zerops-llm-script.ts` (the root `prebuild` script). Never edit them by hand.
