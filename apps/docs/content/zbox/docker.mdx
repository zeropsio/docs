title: Docker in sandboxes
description: Fully working Docker inside Zerops Box sandboxes is coming soon.
---

A sandbox is a full virtual machine with its own kernel, so it is a natural place to run the Docker engine and containers next to an agent.

:::note Coming soon
A fully working Docker integration in sandboxes: run the Docker engine and your containers inside a sandbox.
:::

Until then, if you need a container image as the environment of a sandbox, use it as a base: pull it from a registry or build it from a Dockerfile on the workspace, see [Images](/zbox/images).
